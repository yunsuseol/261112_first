## 복습 코멘트

1. **줄바꿈과 문단**  
   README 본문에서 엔터 한 번은 보통 화면에 줄바꿈으로 표시되지 않습니다. 같은 문단에서 줄만 바꾸려면 **줄 끝에 공백 두 칸**을 넣거나 `<br>`을 씁니다. 빈 줄을 한 줄 넣으면 새 문단입니다. GitHub 이슈·PR·토론에서는 엔터 한 번으로도 줄이 바뀝니다.

2. **제목, 태그, 이슈 번호**  
   `# 제목`처럼 `#` 뒤에 공백을 넣어야 제목이 됩니다. `#공부`가 태그로 처리되는지는 앱마다 다릅니다. GitHub 이슈나 PR 대화에서는 `#12`가 자동 링크로 연결됩니다. README에서 이슈로 연결하려면 `[이슈 #12](이슈 주소)`처럼 링크를 직접 넣습니다.

3. **별표와 번호 목록**  
   `* 항목`은 목록, `*항목*`은 기울임, `\* 항목`은 별표가 붙은 일반 문장입니다. 번호 목록은 **첫 항목의 번호**부터 이어집니다. 같은 목록에 `1.`, `2.`, `3.`, `0.`, `1400234.`를 차례로 써도 화면에서는 `1, 2, 3, 4, 5`로 표시됩니다.

4. **구분선과 주석**  
   일반 문장 바로 아래에 `---`를 붙이면 위 문장이 2단계 제목으로 표시될 수 있습니다. 구분선으로 쓸 때는 앞에 빈 줄을 넣습니다. `Ctrl + /`는 편집기 단축키이고, 파일에 쓰는 주석 문법은 `<!-- 내용 -->`입니다.

5. **표 정렬과 HTML 태그**  
   표 앞에는 빈 줄을 하나 둡니다. `:---:`는 **표 전체가 아닌 셀 안의 내용**을 가운데 정렬합니다. `<center>`와 `<mark>`는 HTML 태그이며, 표시 여부는 앱에 따라 달라질 수 있습니다.

6. **링크와 이미지 경로**  
   `docs/practice.md`나 `images/nz.jpg`는 현재 README 파일이 있는 위치를 기준으로 찾습니다. 예시를 실제로 쓰려면 저장소의 파일 경로에 맞게 바꿉니다. 이미지의 `[]` 안에는 이미지 내용을 설명하는 대체 텍스트를 씁니다.
